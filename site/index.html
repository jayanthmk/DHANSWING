What should the files contain?

Positions: one row per open holding. Use columns Symbol, Quantity, AvgCost, Managed, LastAverageDate. Set Managed to Yes only for positions governed by this strategy. LastAverageDate is optional until you average.

Daily prices: one row per symbol per trading day, with Symbol, Date, Open, High, Low, Close. Include at least 253 completed daily candles per symbol to check a 52-week high. Upload historical prices for the symbols you want to scan.

The template workbook has both sheets. You can also upload the two CSV files separately. Prices must be daily bars; the app uses the latest date in your file.
